Privacy Policy

Last updated: 8 November 2026

Volyx Lens is a desktop application for macOS, Windows and Linux. This policy covers the Volyx Lens app and the static website at volyxlens.pages.dev.

The website

This site is a static Cloudflare Pages deployment. It does not run advertising, analytics, tracking pixels or session recording. It stores one preference in your browser: the light or dark theme you choose.

Cloudflare serves the site and may process standard request data such as IP address, user agent and requested URL to deliver and protect the service. Volyx Lens does not operate a separate analytics dashboard or build visitor profiles from that data.

The app

  • Screen, microphone and system audio are captured only when you enable the relevant source and ask for an answer. Capture is visible in the panel.
  • Selected context is sent directly to the response or transcription provider you configure. There is no Volyx Lens relay server in that path. The provider's own terms and retention policy apply.
  • API keys are stored in the operating system's secure storage where it is available. If secure storage is unavailable, the app keeps keys in memory for the current session and says so in Settings.
  • Transcripts, meeting history, saved Task Context screens and personal context documents stay on your device. They are optional and can be removed in the app.
  • The app contains no analytics SDK and does not send usage telemetry.

Update checks

Volyx Lens asks GitHub for the latest release when update checks are enabled. That request includes your IP address and user agent. You can turn update checks off in Settings → Updates.

Recording and consent

Capture permissions are explicit, but local consent and recording laws still apply. Do not capture people without their permission. Screen-capture exclusion is best-effort and is never guaranteed.

Deleting data

Saved transcripts, meeting history, Task Context screens and personal context can be deleted from the app. Uninstalling the app does not automatically remove files you exported or data your provider retains under its own policy.

Contact

Privacy questions or deletion requests can be opened at github.com/dk3yyyy/volyx-lens/issues (opens in a new tab). Security reports should use the security policy (opens in a new tab).
