Keys stay local

Provider credentials use Electron secure storage backed by the operating system: macOS Keychain, Windows DPAPI, Linux libsecret. If secure storage is unavailable, keys are kept in memory for the session only and are never written to disk; Settings says so.

No analytics SDK

There is no advertising or analytics SDK in the app. The only network calls are the provider and transcription requests you configure.

The only periodic request is the update check: while notifications are on, the app asks GitHub Releases for the newest version shortly after launch, every six hours, and once shortly after the machine wakes if six hours passed while it slept. Those requests necessarily carry your IP address, the updater's user agent, a random updater ID stored on this device, and the platform-specific update channel. Turning notifications off in Settings → Updates stops the scheduled check.

Useful context still needs judgment.

Capture permissions are explicit, but local consent and recording laws still apply. Do not capture private conversations, protected work, exams, or interviews when you lack permission.

Capture exclusion is best-effort. On macOS the app asks the system to keep its window out of captures; on Windows 10 2004 or later it uses WDA_EXCLUDEFROMCAPTURE. Linux has no capture-exclusion API, so the window can appear in screen shares there, and newer macOS capture paths or a physical camera can still record it anywhere. Never rely on it to bypass disclosure, supervision, proctoring, or security controls.

A few direct answers.

The parts people ask before installing: storage, signatures, offline use, and what the app keeps.

Does Volyx Lens operate its own AI backend?

No. You configure your own supported provider. Requests travel from the desktop app to that provider, and the provider's own data terms apply.

Where are API keys stored?

The app uses Electron secure storage backed by the operating system (macOS Keychain, Windows DPAPI, Linux libsecret) when available. If secure storage is unavailable, keys are kept in memory for the session only and are never written to disk; Settings says so and lets you update or remove them. They must be entered again after a restart.

Is the release notarized?

The v0.7.7 macOS DMGs attached to the release are unsigned, so macOS blocks a plain double-click. Drag Volyx Lens into Applications, then run xattr -cr "/Applications/Volyx Lens.app" once in Terminal, or right-click the app and choose Open. If macOS says the app is damaged, that Terminal command is what clears it. The macOS build will be signed with an Apple Developer ID and notarized once release signing credentials are configured. The Windows and Linux builds ship unsigned; every file has a .sha256 checksum, a CycloneDX SBOM is attached per platform and architecture, and Windows shows a SmartScreen "Unknown publisher" warning.

What works offline?

AI responses require a configured provider; with a local Ollama server they run fully offline. Realtime transcription uses your configured provider (OpenAI, Azure Foundry, Deepgram, or Azure AI Speech), and Local Whisper covers offline batch transcription and ships in the Windows and Linux packages (macOS packages cannot bundle one, so there it works only when a whisper-server binary is configured); automatic cloud fallback remains off by default.

Can Volyx Lens detect and save meetings?

Yes. Meeting detection is opt-in; meeting history is on by default for new installs. While listening, meeting detection looks for a sustained two-sided conversation between the Mic and System channels, then tags the session locally with a "Meeting in progress" indicator. With meeting history on, saved meetings get a meeting badge and stay searchable; you can export records, transcripts, or generated meeting notes. Detection runs in-session. Saved history stays on this device and Volyx Lens never uploads it; generating notes or cleaning a saved transcript does send that transcript to the provider you configured.

Can I choose the transcription language?

Yes. The settings screen lets you pick a language for transcription or leave it on auto-detect. Language selection is honored per job and normalized for both cloud providers and the optional local Whisper provider.

Yes. The public source is licensed under the Apache License 2.0, which permits commercial use, modification, and redistribution.
