05 · Before you install

Unsigned builds, keys, offline limits.

macOS builds are unsigned

Drag the app into Applications and try to open it once. On macOS 15 and later, go to System Settings → Privacy & Security and choose Open Anyway. On macOS 13–14, right-click the app and choose Open. xattr -cr "/Applications/Volyx Lens.app" is an advanced fallback. It runs as a panel rather than a Dock app, so there may be no Dock icon; reopen it from Applications. The build is not notarised, so macOS may ask for Screen Recording permission again after an update.

Windows shows an unknown publisher warning

The Windows installer is unsigned. SmartScreen may say "Windows protected your PC"; choose More info and then Run anyway.

Updates check GitHub every six hours

Volyx Lens asks api.github.com for the latest release. That request includes your IP address, a user agent, and on signed builds an updater ID. Turn update checks off in Settings → Updates.

Keys are stored on your machine, not on a Volyx server

Credentials use macOS Keychain, Windows DPAPI, or Linux libsecret/KWallet. If secure storage is unavailable, keys stay in memory for the session and are never written to disk.

What works offline

With a local Ollama server, responses run offline. Local Whisper covers offline batch transcription on Windows and Linux after you enable it and download a model; macOS supports offline batch transcription when a whisper-server binary is configured.

Recording law is still yours

Capture permissions are explicit, but local consent and recording laws still apply. Do not capture private conversations, protected work, exams or interviews without permission. Capture exclusion is best-effort and never guaranteed.
